ПОЯСНИТЕЛЬНАЯ ЗАПИСКА

1. Наименование проекта
Brine Warrior — телеграм-бот для модерации, сбора статистики и информирования администраторов канала/чата.

2. Цель разработки
Создание инструмента для автоматического мониторинга активности в Telegram-чатах, выявления аномального поведения (спам, флуд, резкий рост аудитории) и формирования аналитических отчётов. Бот призван снизить нагрузку на живых модераторов за счёт раннего оповещения о подозрительной активности и автоматического сбора метрик.

3. Технический стек
Проект реализован на Python 3.11+ с использованием асинхронного фреймворка python-telegram-bot (v20+). В качестве базы данных для оперативного хранения статистики используется SQLite, дополнительные временные данные кешируются в JSON. Валидация внутренних объектов осуществляется через Pydantic.

4. Функциональные возможности

Статистика (Statistics): Сбор и агрегация данных о сообщениях, вступлениях/выходах участников. Доступ к статистике предоставляется по командам администраторам.

Модерация (Moderation): Выявление аномалий (резкие всплески сообщений, однотипный текст от разных пользователей) и уведомление администраторов (алерты).

Дайджест (Digest): Автоматическая периодическая выгрузка сводки по ключевым метрикам чата за период.

Настройка (Settings): Гибкое включение/отключение отслеживания определённых метрик непосредственно из интерфейса бота.

5. Структура и логика работы компонентов
Проект построен по модульному принципу и разделён на слои обработки команд, бизнес-логики и хранения данных.

Точка входа (bot/main.py): Инициализация бота, загрузка конфигурации из .env и запуск асинхронного поллинга обновлений Telegram.

Обработчики (bot/handlers/): Прослушивают команды и сообщения.

start.py — авторизация, проверка прав администратора.

stats.py — вывод накопленной статистики.

settings.py — интерфейс настройки фильтров мониторинга.

help.py — справка по доступным командам.

digest.py — управление подпиской на дайджест и его ручной запрос.

Сервисный слой (bot/services/): Содержит "мозг" системы.

collector.py — перехватывает каждое событие (апдейт) из чата и препарирует его для сохранения в БД.

analyzer.py — в реальном времени сравнивает текущий поток данных с нормами, выявляя спам-атаки или накрутку ботов.

notification.py — рассылает уведомления админам при срабатывании триггеров анализатора.

digest_builder.py — по расписанию формирует текстовый/графический отчёт.

Модели (bot/models/): Классы Pydantic для строгой типизации данных, передаваемых между анализатором и сборщиком (не путать с таблицами БД).

6. Инфраструктура и CI/CD

Контейнеризация: Присутствует Dockerfile и docker-compose.yml для быстрого развёртывания на сервере с подключением data/ как volume для сохранности базы данных.

Логирование: Все критические ошибки и действия модерации сохраняются в папку logs/.

CI: В директории .github/workflows настроен lint.yml для автоматической проверки стиля кода при каждом пул-реквесте.

Makefile: Содержит шорткаты для разработки (очистка БД, перезапуск, прогон тестов).

7. Заключение
Бот "Brine Warrior" реализует легковесное, не требующее тяжёлых БД решение для поддержания
порядка в активных сообществах Telegram. Асинхронная архитектура позволяет обслуживать множество
чатов одновременно, а система алертов помогает реагировать на инциденты до того, как они перерастут
в серьёзную проблему.
